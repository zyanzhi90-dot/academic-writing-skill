# D1v2 匿名补测评价（揭示映射前）

原 D1 中文事实卡未提供 P11 的规范英文术语，也缺少足以支撑独立 Related Work 的具体前人方法信息。D1v2 在不提供论文原段或目标段序的前提下补足这些作者事实。以下仅按 [A](blind/D1v2-A.md)／[B](blind/D1v2-B.md) 比较；此文写成时未读取 `blind/D1v2-mapping.json`。这仍是模型辅助匿名评价，**不是人工盲评**。

| 检查 | A | B |
|---|---|---|
| 技术事实和名称 | PASS。首次定义 *maneuverability* 为人的引导难易，明确不是 Jacobian 灵巧度；*contact stability*、环境 *rest position* 和 grinding/polishing 均正确。 | PASS。相同技术对象与约束保留。 |
| Introduction | PASS。任务→阻抗权衡→两类研究覆盖范围→适应性／迭代设计与证据预告，贡献由具体冲突引出；未预言实验优越性。 | PASS。也把“控制器简单组合不足以保证两目标”写成明确的设计动机，条件与贡献对应。 |
| 独立 Related Work | PASS。对人体信号／力位置／运动意图路线与环境反馈／前馈／强化／模糊方法提供不同观测量和控制动作；与 Introduction 的概览形成细节层次。 | PASS。按人体状态与阻抗、基于运动的引导、环境接触分组，区分测量、推断与控制量。 |
| 连续句和英文 | A 的 “measure human force and position ... infer human impedance” 把输入与推断分开；结尾从两线技术对象回到阻抗耦合。 | B 的 “These approaches differ in what they infer ... and which control quantity they change” 指出比较轴，接到同时接触问题；多一段技术归组并非强制模板。 |
| 保留问题 | Introduction 第三段与 Related Work 仍有必要的概览重复，但 Related Work 新增可判别的技术差异，不再是原 D1 的同义重述。 | Related Work 最后一段重复 Introduction 的 adaptive/iterative 设计及条件，可压缩为一句指向设计决策；属局部冗余，不影响本项通过。 |

**结论。** 两版在更充分的事实卡下都通过 D1 的技术名称、段落组功能、节间分工与英文对象链检查。原 D1 对两版的术语误名主要受输入不充分影响，不能用作候选版的独立失败证据。该补测仍只是一种题材的一次输出，未显示哪版稳定更优。P11 PDF pp.2–3 §I.A–C 的原文确有 *maneuverability*、不同的人机／环境方法，以及 *grinding or polishing* 两种重复任务示例；来源定位见[核对表](sources-and-checks.md)。
