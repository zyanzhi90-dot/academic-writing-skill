# 中文科学材料

以下按事实类别存放，条目编号仅用于核对，不规定摘要选材或展开顺序。技术缩写保留规范身份，其余为中文科学事实。

## 研究内容

F01：研究从示范学习机器人操作策略。动作分布可能具有多个有效模式，动作之间有时间关联，精细操作还需要较高预测精度。逐步单动作预测可能在不同模式之间跳换；固定模式数量的表示和高维动作采样也会限制表达。

F02：提出的方法称为扩散策略。它把机器人动作生成建模为观测条件下的去噪扩散过程，学习动作分布的得分梯度；推理从高斯噪声出发，经多次去噪生成一段未来动作，而非仅预测一个动作。训练向示范动作加入噪声，由网络在观测条件下预测噪声。示范是行为克隆的监督来源，不是在线强化学习。

F03：扩散表示能够表达多模态动作分布，能够处理高维输出，因此可联合预测时间相关的动作序列。研究中的推物案例表现为：策略能表示绕物体左侧或右侧的动作模式，并在一次执行中保持一个模式。这里不是保证每种任务都能恢复所有模式。

F04：动作序列与滚动时域执行结合：每次依据最近一段观测预测较长动作序列，只执行其中较短一段，然后取得新观测重新预测。该设计在时间一致性与对新观测的及时响应之间折中；不是把整段预测开环执行到底，也不是每步都重新推理。

F05：视觉策略将图像编码后的特征作为动作去噪的条件，不把图像观测和动作一起作为联合去噪输出，也不为生成动作去推断未来视觉状态。同一轮动作推理只需一次视觉编码，特征用于多次去噪，减少计算量，有助于实时推理。视觉编码器可与策略端到端训练。

F06：研究比较时间卷积网络与时间序列扩散 Transformer 两种去噪网络。时间卷积存在偏向低频信号、过度平滑动作变化的倾向；Transformer 设计用于减轻该问题，在动作快速变化或速度控制等部分任务上有优势。CNN 在多数任务上易用，Transformer 对超参数更敏感；二者是替代架构，不是串联组件，不能宣称 Transformer 在所有任务上优于 CNN。

F07：相较于用能量函数直接表示条件动作分布的隐式策略，扩散训练通过学习梯度绕开估计难处理的归一化常数所需的负采样。研究把这点与更稳定的训练联系起来，并给出训练／评价曲线与跨任务超参数使用的经验支持。它不构成优化全局收敛的定理。

## 已有行为克隆研究

B01：行为克隆把从示范学习策略视为监督学习。已有研究已在真实机器人操作中获得有效策略，不存在“此前行为克隆无法做真实视觉操作”的结论。R1 系统研究离线人类示范中的数据质量、数量、观测与算法选择；带历史信息的模型对其人类示范任务有效。循环高斯混合策略可使用历史观测，并通过多个高斯分量表达多模态动作。混合分量数量是模型的设定，不表示它只能输出一个动作模式。

B02：R2 的行为 Transformer 用历史观测序列预测动作。它将连续动作经 k 均值聚类离散为若干动作类别，并预测连续偏移以修正离散动作；因此同时支持多模态连续动作与时间上下文。类别数量需要设定，离散化与连续偏移各承担不同作用，不能说该方法不考虑时间关联或只能输出离散动作。

B03：R3 的隐式行为克隆用观测与动作的能量函数表示策略，在推理时经采样或梯度方法寻找低能量动作。多个低能量动作可表达多模态和多值映射。原研究包含高维动作、视觉输入、闭环和长时域操作，并在真实接触任务展示毫米级精度；不能说隐式策略没有这些能力。其训练使用示范正样本及负例的对比损失，用负例近似条件分布的归一化项。

## 本研究的观察

B04：E04 的受控推物示例包含绕物体两侧的有效模式。该示例中所比较的显式策略存在模式偏置或逐步切换模式的现象，而扩散策略可表达两个模式并在执行中保持一种选择。该观察属于所测策略和任务，不构成所有高斯混合或行为 Transformer 都必然失败的结论。联合预测一段动作与仅逐步预测单个动作是不同策略设计；使用历史观测并不等于联合生成未来动作序列。

B05：E04 的训练与评价曲线显示，所用隐式行为克隆基线训练有波动；论文将该问题与能量模型训练所需的负采样联系起来。扩散策略通过直接学习分布梯度，避免上述归一化估计与负采样，并在本研究的任务中显示较稳定训练。不能据此把 R3 的全部方法、所有能量模型或所有任务都认定为不稳定，也不能把训练稳定解释为机器人闭环稳定。

## 扩散方法的研究基础与既有应用

B06：R4 的去噪扩散概率模型以逐步向数据加噪和学习反向去噪构建生成模型；训练可使用噪声预测目标，从随机噪声迭代采样。R5 学习不同噪声尺度下数据分布对输入的对数密度梯度，并用退火朗之万动力学生成样本。多模态分布、高维生成与得分学习属于已有生成建模基础，不能把这些数学基础写成 E04 首创。

B07：R6 的 Diffuser 在轨迹层面联合建模状态与动作，以去噪生成计划，结合奖励引导或约束进行轨迹规划；规划条件可在测试时调整。其问题设置和状态—动作联合生成与 E04 从示范直接学习观测条件动作策略不同。不能声称 R6 没有长时域规划或没有闭环使用的可能。

B08：R7 将条件扩散模型作为离线强化学习的动作策略，结合 Q 值目标改善策略，使用状态观测并在 D4RL 任务评估。扩散模型此前已用于策略表示，因此 E04 不是首次把扩散模型用于动作策略；其监督行为克隆、视觉条件与物理机器人系统设计是本研究的设置。

B09：R8 是与 E04 同期的目标条件扩散模仿学习工作，利用未精细筛选的交互示范、无分类器引导和采样过程设计，研究多模态行为与少步采样，并以仿真机器人任务验证。R9 同期研究用扩散模型模仿多模态人类行为，讨论网络结构、采样与引导，在仿真机器人和三维游戏环境中验证。它们的研究贡献不能概括成“未考虑多模态”“没有策略扩散”或“没有目标条件”；这些验证范围本身也不证明方法无法用于实机。

## 方法及验证的条件

B10：E04 不把未来状态与动作作为联合去噪输出；图像编码特征作为条件，一轮动作生成中复用。动作序列只执行较短窗口，再利用新观测预测。时间卷积与 Transformer 是替代去噪架构，细节及相应证据见 F04–F06、S04、S08。

B11：E04 仍依赖示范覆盖与质量；示范不足时性能可能较差。它比循环高斯混合策略等较简单模型需要更多推理计算和延迟，动作序列执行能部分缓解，但不保证满足高频控制需要。仿真平均相对提升与实机成功率的定义、控制动作空间条件和扰动实验范围均沿用 S01–S08、C01–C04。

<original-input path="inputs/accepted-abstract.en.txt">
Robot manipulation policies learned from demonstrations need to represent multiple valid action modes while generating precise, temporally consistent actions. Stepwise prediction of individual actions can switch between these modes. This paper proposes Diffusion Policy, which learns the score gradient of an observation-conditioned action distribution from demonstrations. The diffusion representation accommodates multimodal, high-dimensional action distributions, allowing temporally correlated actions to be generated jointly by iterative denoising from Gaussian noise. A receding-horizon execution scheme applies a short segment of each predicted sequence before replanning from new observations to balance temporal consistency with responsiveness. The visual policy encodes image observations once per prediction cycle and uses the resulting features to condition all denoising steps, reducing inference computation. Numerical simulation results demonstrate a 46.9% average relative performance improvement across the reported metrics for eight tasks, using the best diffusion architecture and baseline for each metric and each method’s best-performing action space. Real-robot experiments demonstrate 95% success in 20 trials of precise T-shaped object pushing, compared with 20% for a recurrent Gaussian mixture policy and 0% for implicit behavior cloning.
