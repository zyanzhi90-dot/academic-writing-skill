Neural Control of Robot Manipulators With
Trajectory Tracking Constraints
and Input Saturation
Chenguang Yang , Senior Member, IEEE, Dianye Huang , Graduate Student Member, IEEE,
Wei He , Senior Member, IEEE, and Long Cheng , Senior Member, IEEE
Abstract—This article presents a control scheme for the
robot manipulator’s trajectory tracking task considering output
error constraints and control input saturation. We provide an
alternative way to remove the feasibility condition that most
BLF-based controllers should meet and design a control scheme
on the premise that constraint violation possibly happens due
to the control input saturation. A bounded barrier Lyapunov
function is proposed and adopted to handle the output error
constraints. Besides, to suppress the input saturation effect,
an auxiliary system is designed and emerged into the control
scheme. Moreover, a simplified RBFNN structure is adopted to
approximate the lumped uncertainties. Simulation and exper-
imental results demonstrate the effectiveness of the proposed
control scheme.
Index Terms—Barrier Lyapunov function (BLF), constrained
control, input saturation, robot manipulator.
I. INTRODUCTION
CONSTRAINTS on output error commonly exist in engi-
neering applications and are often interpreted as the
performance requirement and safety specification [1], [2].
Constraint violation may degrade the control performance
or even cause unexpected system damage. To tackle this
problem, some constrained control methods have been inves-
tigated extensively these years, to name a few, the command
governor [3], unbounded coordinate transformation method
[4], and the nonovershooting control [5]. These methods either

indirectly. Recently, the barrier Lyapunov function (BLF) has
attracted more and more attention and acts as an effective
tool in the control design for constrained nonlinear uncertain
systems. The control law is derived directly from the Lyapunov
stability analysis. Successful applications can be found in
the prescribed tracking performance control of serial robot
manipulators [6], handling the tracking error constraints effect
on the marine surface vessel [7] and the full state-constrained
control for nonlinear systems [8].
So far, many types of BLF have been proposed to handle the
constraint effect, such as the log-type BLF [9], the integral-
type BLF [8], and the tan-type BLF [10]. However, at the
beginning of the control, a BLF-based controller usually needs
prescribed time-varying transient performance constraints to
achieve valid and stable control, as in [1] and [6]. Besides,
to satisfy the constraints when the constrained variables lim-
itlessly approach the predefined boundaries, the control input
of a BLF-based controller tends to be infinite, which results in
a paradox for the existence of the input saturation. Therefore,
to handle the constraints, the BLF-based controller should
meet the feasibility condition in [11], i.e., the constrained
variable should always stay within the predefined boundaries.
Parameters should also be appropriately designed, as it may
be impractical if the constraints region is too small. Much
research work has been made in [11] and [12] to remove the
strict feasibility condition. In these works, the time derivative
of the universal barrier function in [13] is regarded as an
auxiliary system, which is subsequently incorporated into
the control system. Then, the controller for the augmented
system is designed under the dynamic surface control scheme.
However, in authors’ opinion, this method only partially
relaxes the feasibility condition because of two points: 1) the
initial system states still need to satisfy the constraints and
2) the control law will be discontinuous when the constrained
variable equals to the constraints, and the case involving
constraint violation has not been studied in the simulation.
To further narrow the reality gap and to provide an alternative
way to remove the feasibility condition radically, a new type
of BLF should be designed and have the following properties:
1) be positive outside the constrained space and 2) the partial
derivative with relative to the constrained variables be bounded
at the whole space. To the best of our knowledge, there is

For constrained control, the input saturation effect, repre-
senting the capacity limitation of a plant, is a nontrivial source
of the degradation of system performance or even system insta-
bility if not being properly handled with [14]. In [15], the input
saturation effect is formulated as a model predictive control
problem, and then, the proposed algorithms are adopted for
estimating the upper bound of the control horizon, while this
method is only suitable for linear time-invariant system. Model
predictive control is widely used in the chemical industry and
is able to handle input saturation. The control barrier function
is also one of the methods to verify and enforce the safety
properties of a plant. It is applied to the safety-critical control
and unified with the Lyapunov function through quadratic pro-
gramming to track the reference signals [16]. However, these
methods are of high computational burden when the controlled
plant is complex, nonlinear, and with uncertainties. To handle
the output constraints and the input saturation simultaneously,
an adaptive control framework would be a better choice.
Wu and Xie [17] employed time-varying asymmetric BLFs,
an auxiliary subsystem, and the Nussbaum gain technique to
design an adaptive controller for uncertain nonlinear systems
with time-varying full state constraints, input saturation, and
unknown control direction. Yan et al. [18] introduced a nonlin-
ear smooth function to tackle the saturation input nonlinearity,
with HODOs compensating the unknown time-varying distur-
bances. In [19], the adaptive fuzzy output-feedback control is
developed for a class of output-constrained uncertain nonlinear
systems with input saturation and unmeasured states using
a log-type BLF and an auxiliary system incorporating into
the virtual control variable. This framework is refined and
systematically illustrated in [14], where the input and output
constraints are circumvented simultaneously. In the process
of controller design, in order to obtain a smooth control
law, the saturation function (τ) is replaced with a hyper-
tangent function tanh(τ) in [14], and the auxiliary system is
driven by the discrepancy between τ and tanh(τ). However,
the nonlinearity of tanh(·), to some degree, may degrade the
control performance since the states of the auxiliary system
representing the influence of the input saturation will not
converge to zero when the control input is not equal to zero.
This article considers both the output error constraints
and the input saturation of robot manipulators and presents
a trajectory tracking controller to fulfill these requirements
simultaneously. Comparing with the existing results, the con-
tributions of this article are summarized as follows.
1) A bounded BLF (BBLF) is proposed. Different from
most of the existing BLF-based controllers, the proposed
BBLF-based controller in this article is designed on the
premise of taking the case when constraints violation
occurs into consideration.
2) Inspired by [14], a modified auxiliary system is intro-
duced to handle the input saturation effect, where the
system states will converge to zeros if no control input
saturation occurs.
3) A simplified RBFNN structure is adopted to greatly
reduce the complexity of the network. Furthermore,
a simple criterion is proposed to quantify the contribu-
tion of the four items that constitute the proposed control
law, so as to examine their respective effectiveness.

VII. CONCLUSION
A trajectory tracking controller for robot manipulators is
developed considering both the output error constraints and the
control input saturation effects. Using the BBLF to handle the
constraints’ effect, we guarantee that the system could remain
stable when the output errors go beyond the constrained
boundaries. A modified auxiliary system and a simplified
RBFNN structure are also incorporated to improve control
performance. Simulation and experimental results demonstrate
the validation and the superiority of the proposed method.
