## B15 / P17：从示教运动生成推进到可靠执行

### 具体科学逻辑链

机器人广泛用于制造等领域，产品更新加快使适应性成为需求 → 增强机器人学习，LfD 通过示教与运动建模复现技能，因此运动怎样建模是首个问题（I01） → DS 提供稳定、可扩展、抗扰的运动表示，但所举的一种 DS 学习方法需要较多示教数据；DMP 保留动态系统的稳定、抗扰性质且可由一次示教建模，成为选用的运动表示（I02） → DMP 已支持快速运动、动作组合与风格调节，但最优示教难以获得，多次示教可能隐含理想轨迹，因此作者提出把多次示教整合进一个 DMP（I03） → 概率方法能够保存示教变异与更多特征，GMM／GMR 有多示教编码与生成能力，SEDS、DS-GMR 已展示动态系统与统计学习结合的价值（I04） → 用 GMM 建模 DMP 的非线性函数、由 GMR 提取估计，使一个 DMP 从多次示教中合成运动特征；再与只从一次示教学得 DMP 的方法及另一种逼近方法比较，说明该选择的相关价值（I05）。

到这里解决的是“生成什么运动”。论文随后明确：模仿性能还取决于“是否准确执行生成的轨迹” → 准确模型有利于跟踪，但未知负载等使精确动力学难以事先取得 → 需要函数逼近补偿；由 NN 能力与 RBFNN 的实时控制适用性，推进到 RBFNN 自适应跟踪控制器（I06） → 运动生成输出关节空间轨迹，控制器跟踪这些同一轨迹并补偿不确定动力学，稳定性由 Lyapunov 分析保证（I07） → 相对只考虑运动建模的指定工作，本文的贡献是把多示教运动生成与可靠执行连成完整机器人学习框架（I08），最后给出章节导航（I09）。

这里的核心不是“先综述 DMP，再综述 NN”的主题并置，而是同一个机器人学习任务的两项连续责任：先学得有代表性的运动，再让机器人在不确定动力学下执行它。I06 的进入理由来自此前运动生成的实际用途。

## B16 / P05：从相对运动任务推进到 NN 学习条件

### 具体科学逻辑链

双臂系统具有更强负载、更大工作空间和更高灵活性，已有多种应用；与此同时，其运动控制与路径规划复杂，使先进协调控制值得研究（I01）。这两方面是并列背景，不能由双臂优势推导控制复杂性。

已有协作控制能够处理物体搬运、力／位置调节、内力与负载问题，但这些工作的共同条件是物体被机械臂牢固持握、臂与物体之间没有相对运动 → 抛光、磨削、焊接等任务却需要末端沿物体表面滑动，因此需要研究非对称双臂相对运动（I02） → 已有相对阻抗、脑机接口等方案能够处理这类任务，但所述工作假设动力学完全已知，且未给出接触力稳定性分析（I03） → 实际抓持对象动力学往往不能预先取得，需要补偿模型不确定性；NN 的非线性逼近能力提供了一个相关方法方向（I04） → 已有自适应 NN 控制解决了多种控制问题，但作者指出跟踪误差收敛不等于 NN 权值收敛到理想值，进而把可靠 NN 补偿推进为权值学习收敛问题（I05）。

权值收敛需要合适的激励条件 → 对稀疏 NN 回归向量，传统 PE 难满足；PPE 可利用规则格点 RBFNN 的局部激活，但引用的后续方法仍需输入回返轨迹，小激励又可能学习慢（I06） → 把估计误差信息引入自适应更新已有提高参数／权值收敛的依据，因此本文为未知动力学下双臂相对运动设计复合学习控制，并引入 PPE 放宽传统 PE 要求、适当表达和利用 NN 权值估计误差改善逼近（I07） → 最后将“未知动力学下的非对称双臂控制框架、估计误差信息参与复合学习、较宽松的激励条件”列为贡献（I08、C1–C3），再导航（I09）。

这条链从任务条件进入补偿需要，再进入补偿方法的学习保证。复合学习和 PPE 是对已经建立的学习问题的回应，不是突然添加在双臂控制末尾的技术名词。接触力稳定性是 I03 的相关局限；贡献列表并没有把它单独列为第四项成果，本轮不替原文补足。

## B17 / Fuzzy2023：两项性能需要分别推进，再合成控制目标

### 具体科学逻辑链

机器人运行中模型参数时变、外部扰动造成不确定非线性项 → 自适应 NN／FLS 具有通用逼近能力，可以支持不确定机器人跟踪控制；原文列出约束、交互和康复等既有能力 → 作者同时提到传统模糊控制的权值迭代计算负担，随后提出多数现有模糊控制较少同时讨论期望瞬态性能与收敛时间这一关注点（I01）。计算负担与核心性能问题是同段的不同议题；原文把结构优化明确留作未来工作，不能说本文已经用固定时间／BLF 解决了计算负担。

主线从这里分为两项并列性能需要。第一项：不良瞬态可能影响稳定性与安全 → BLF 已能处理状态／输出约束，相关工作提供约束与时间性能结合的能力 → 本文设计对称 BLF，保证机器人期望瞬态性能（I02）。第二项：工业系统需要快速收敛 → 有限时间控制已有相关能力，但收敛时间依赖有时不可得的初始条件 → 固定时间控制提供不同的时间保证，已有固定时间模糊控制与约束结合的工作可供承接（I03）。

两项需要最终与 I01 的不确定性处理合流：针对不确定机器人，把 FLS 与 BLF 纳入固定时间跟踪控制（I04） → 贡献依次为对称 BLF 的输出约束／瞬态保证、新自适应律所保证的闭环信号有界并放宽已有研究的权值估计有界假设、与初始条件无关的实用固定时间收敛（C1–C3）。

这里不能把“瞬态性能需要”写成“初始条件不可得”的原因，也不能把“多数工作较少同时讨论”扩大为“此前没有工作同时实现”：I01 明确承认 [8] 已有固定时间与用户定义性能相结合的机器人方案。新自适应律所放宽的权值有界假设在贡献 C2 才明确出现，正文背景并没有为它单独设置一段前置论证；应如实保留这个展开程度。

## B18 / ESO2017：扰动补偿需要与不可测速度需要汇合

### 具体科学逻辑链

水下机器人扩展海洋资源探索与科学研究能力 → 数据质量、轨迹跟踪和定点保持依赖高精度控制（I01） → 海洋波浪、潮汐、水流及缆绳力形成未知扰动，水动力系数计算不准与姿态变化形成模型不确定性，说明高精度控制的现实障碍（I02） → 自适应、鲁棒和观察器控制均有相关能力；NN／模糊逼近可处理不确定性和扰动，但实际学习参数调整仍困难（I03–I04）。

SMC 是另一种抗扰工具，ISMC 的积分项有助于提高轨迹跟踪精度，但 SMC 抖振造成能耗与轨迹不平滑；不确定性上界较大而缺少补偿会加剧抖振 → 需要对外扰进行补偿（I05） → 观察器可先估计扰动、再供控制补偿，相关工作展示降低控制增益、估计未知扰动，以及同时估计不确定性和不可测状态的能力（I06）。

与此同时，本文实际可取得深度、姿态和视觉位置，却无法直接测得速度；直接微分位置又可能损害控制性能 → 需要输出反馈及不可测速度估计，相关状态观察器已展示速度、状态和扰动估计能力（I07） → 将“为减轻抖振而估计／补偿扰动”与“为输出反馈而估计不可测速度”两项需求汇合，提出自适应 MIMO-ESO 同时估计扰动和不可测状态，再以自适应不确定性界估计及 Lyapunov 设计的 ISMC 保证轨迹跟踪（I08） → 贡献为联合估计、相应跟踪控制，以及实验中与 PD 控制的比较验证（C1–C3），最后导航（I09）。

I06 结尾涉及某项已有 ESO 工作的带宽选择，要兼顾最大负载能力和动态性能；这只是该工作的设计条件。I06 到 I07 的有效承接是观察器已有扰动／状态估计能力，加上当前速度不可测的具体信息条件，不能由带宽折中推出状态估计需要。两项需要也不是互为因果：有外扰不等于速度不可测，速度不可测不等于抖振。

3. **区分递进、并列、条件与因果。** P17 的生成轨迹需要后续执行是责任递进；Fuzzy2023 的瞬态与收敛时间是并列性能需要；P05 的无相对运动是既有任务条件，双臂优势和复杂性是并列背景；ESO2017 的状态估计需求来自速度不可测，不来自带宽折中。整节可以有多条需要，最终由同一研究目标汇合，不能为了叙事顺滑制造因果。

4. **段落承担一个清楚的科学推进任务，其位置由前后依赖决定。** 一段可以建立对象与价值、说明相关能力、限定成立条件、引入下一项需要、给出设计及作用，或集中贡献。承接前段可以是同一问题进一步具体化，也可以补足前段方案达成研究目的所需的另一项责任。准备后段不等于每段末强行制造 gap；能力已经为下一项选择提供依据时可以直接推进。

5. **已有方法按当前问题选择，既写相关能力，也保留必要条件。** 比较要落在科学维度，如示教信息利用、相对运动假设、权值收敛、初始条件依赖、可测状态与抗扰能力；只对原文支持的对象成立。已有工作已实现的联合性能不能抹去，也不能把指定方法的不足扩成全领域空白。每项被选择的文献材料应帮助读者理解研究需要或设计选择。

6. **在理由足够的位置交代设计，再说明它的具体作用和与其他部分的联系。** 不固定为最后一段，也不必须全部设计一次列出。对多部分系统，可像 P17 那样先推出运动生成，再推出执行保障，随后解释生成轨迹与跟踪控制之间的接口；对并列性能需要，可像 Fuzzy2023 那样分别建立需要再汇合。设计名称本身不能替代为何采用、解决什么和带来什么保证。

7. **Introduction 展开到读者理解采用理由与贡献所需的程度。** 可以交代设计对象、概念性机制、部件职责、输入输出关系和有依据的保证；默认不展开 Method 的内部实现步骤、公式推导、训练／更新过程或证明程序。P17 对 GMM 所建模函数和生成／跟踪关系的交代，是解释设计职责的具体性，而不是算法教程。

8. **默认不展开本研究实验设置、任务清单或结果。** 引言围绕研究需要、已有能力与条件、本文设计和贡献组织。已有工作的应用例证可以解释任务需要；章节导航可以简短定位实验章节，均不同于本研究实验展开。科学问题本身的“速度不可测”等信息条件可以用于建立设计必要性，不因此搬入深度传感器、IMU、VPS、灯光、推进器或比较试验清单。ESO2017 的配置段和实验比较贡献保留为原文特殊处理，不作为默认。

9. **结尾把前文需要收束为本文承担的职责、贡献与保证。** 可用连贯段落，也可用贡献列表；是否追加简短导航取决于稿件需要。重点是贡献能回到已建立的研究对象和需要，不在结尾临时新增另一套主线，也不以实验任务列表代替科学贡献。范例展开不均衡之处如 Fuzzy2023 的 C2 如实记录，不假称其前文已有完整动机。

10. **保留 P17 锚点，其他范例按科学适用关系补充。** P17 提供“研究价值 → 运动学习需要 → 设计 → 执行需要 → 设计 → 框架贡献”的连贯职责关系；P05 补充任务条件与学习条件的推进；Fuzzy2023 补充并列性能需要的汇合；ESO2017 补充扰动与状态估计需求的合流。实际使用取决于作者研究，不固定为这些科学模块、段数、顺序或段末形式。
