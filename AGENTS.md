# Project synchronization

The user has authorized uploading this project's files to `https://github.com/zyanzhi90-dot/academic-writing-skill`.

After completing any change to files in this project, commit and push the changed project files to `origin/main` before reporting completion. Run `./sync.ps1 -Message "<concise change summary>"` from the project root, then verify that the local branch is clean and matches `origin/main`. If a push fails, report the failure and do not claim that synchronization succeeded.

This instruction applies to changes made by Codex in this project. Do not include files outside this project or credentials in a commit.

# Robotics Introduction author inputs

When preparing a new robotics Introduction session, freeze the current project-root `核心要求.txt`, `我自己的经验和做法.txt`, `引言写作方法.txt`, and `current-author-adjustment.txt` as the normal author inputs. Copy the project-root `current-author-adjustment.txt` into the new record and its `inputs/current-author-adjustment.txt`; it supplies the current override. Use fresh hashes for these author inputs. Historical author overrides, frozen author requirements, outputs and diagnoses remain audit records and must not supply the new session's current requirements. Reuse confirmed scientific inputs as authorized. This instruction changes only robotics Introduction input preparation, not the executor or other sections.
